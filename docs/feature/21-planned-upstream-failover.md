# 21. 代理上游故障转移（占位）

状态：📋 计划占位——未排期（iteration-plan R8）

## 功能（目标）

`proxy_pass` 支持多个上游地址：健康检查 + 负载均衡 + 故障转移。上游不可达时自动摘除并切到备节点，恢复后自动加回。

## 需求要点（拟定，待评审）

- 配置：`proxy_pass` 接受地址列表（空格/数组），可选权重。
- 健康检查：被动为主（连接失败/超时计数熔断，半开探测恢复），主动探测为可选。
- 负载策略：首版轮询或最少连接；连接池（已实现）按"上游地址组"扩展键。
- 失败语义：转发失败在幂等方法上重试下一节点；`proxy_next_upstream` 式开关。
- 与现有组件的关系：`upstreamPool` 的键从单地址变为地址组；`DialFailureResponse` 保留为全部节点失败时的兜底错误页。
